# Studio Errant Design Brief

> **Version:** 1.0
>
> **Status:** Living Document
>
> This document defines the philosophy, visual language, interaction principles, and engineering direction for Studio Errant. It is the single source of truth for every future iteration of the website, regardless of whether it is built by a human designer, a developer, or an AI coding assistant.
>
> Every design decision should be evaluated against the principles described here before implementation.

---

# Execution Protocol

Read this document completely before beginning.

Do not start implementation after reading the first sections.

After reading the entire brief:

- Summarize your understanding.
- Identify any conflicts.
- Ask the Discovery Questionnaire.
- Wait.

Implementation must not begin until explicit approval is received.

If there are tradeoffs between visual fidelity, performance, accessibility, or maintainability, explain them before writing code.

# 1. Introduction

Studio Errant is not a portfolio.

It is not a personal website.

It is not a creative agency website.

It is not a product landing page.

Studio Errant is a **digital studio** built around curiosity.

The website exists to communicate an approach to making things rather than simply displaying what has been made.

Visitors should leave remembering how the website made them feel more than remembering any individual project.

The purpose of the experience is to communicate that thoughtful work does not emerge from certainty—it emerges from exploration, experimentation, observation, and wandering.

Everything on this website should reinforce that idea.

Nothing exists purely because it looks impressive.

Every animation, transition, interaction, and piece of typography must support the overall philosophy.

The website should feel calm rather than loud.

Confident rather than flashy.

Timeless rather than trendy.

Minimal without becoming empty.

Artistic without becoming abstract.

Technically sophisticated without drawing attention to the technology itself.

The interface should disappear behind the experience.

Visitors should never think:

> "This website has cool animations."

Instead they should think:

> "That felt different."

---

# 2. Brand Philosophy

The word **Errant** traditionally describes someone who wanders.

Studio Errant embraces wandering as a creative process.

Ideas rarely arrive fully formed.

Most worthwhile ideas begin as questions.

Questions become experiments.

Experiments become observations.

Observations become understanding.

Understanding eventually becomes meaningful work.

Studio Errant exists within that space.

Rather than presenting creativity as moments of sudden inspiration, Studio Errant presents creativity as a slow process of exploration.

Every project shown on the website should feel like evidence of curiosity rather than evidence of expertise.

The website should never attempt to convince visitors that its creator has all the answers.

Instead it should quietly suggest that asking better questions is more valuable than pretending certainty.

Curiosity is not treated as a personality trait.

It is treated as a discipline.

This philosophy should influence every part of the design.

Darkness represents possibility.

Movement represents thought.

Light represents discovery.

Purple represents imagination becoming tangible.

White represents clarity emerging from uncertainty.

Negative space represents room for new ideas.

Nothing on the website should contradict these symbolic meanings.

# 3. Design Manifesto

Every future decision should be measured against the following principles.

## Design for memory, not novelty.

The goal is not to impress visitors for five seconds.

The goal is to remain in their memory long after they leave.

If forced to choose between spectacle and memorability, choose memorability.

---

## Atmosphere over decoration.

Visual effects should create emotional atmosphere.

They should never exist simply because modern websites often include them.

Remove anything that does not support the emotional experience.

---

## Motion should reveal.

Animation is communication.

Movement should help visitors understand hierarchy, transition, attention, or emotion.

Animation should never compete with content.

---

## Stillness is equally important.

A world where everything moves feels chaotic.

A world where nothing moves feels lifeless.

Motion requires stillness to create contrast.

Allow some elements to remain perfectly static.

Silence makes music meaningful.

Stillness makes movement meaningful.

---

## Curiosity should always be rewarded.

Visitors who slow down, observe carefully, or interact thoughtfully should occasionally discover subtle details that are not immediately obvious.

These discoveries should never interrupt usability.

They should simply reward attention.

---

## Build with restraint.

Whenever uncertain between two options, choose the simpler one.

Sophistication should emerge from refinement rather than complexity.

---

## Craft over trends.

Avoid temporary design fashions.

The website should feel contemporary five years from now.

If a design decision feels popular rather than timeless, reconsider it.

---

## Let the interface disappear.

Visitors should focus on ideas.

Not interface elements.

Not transitions.

Not technical implementation.

Technology should become invisible.

# 7. Visual Language

Studio Errant communicates primarily through contrast.

Not through color.

Darkness is the default state.

Light is earned.

The design language should resemble entering a quiet room at night where only a few carefully chosen objects are illuminated.

## Darkness

Black is not used because it looks premium.

Black represents possibility.

It allows ideas to emerge naturally.

Darkness is the canvas upon which everything else exists.

---

## Light

White should be used sparingly.

Every bright element becomes important simply because the environment is restrained.

Light guides attention.

Never overwhelms it.

---

## Purple

Purple should never appear immediately.

It should feel discovered.

As visitors enter creative work, subtle violet and indigo tones should slowly emerge beneath the darkness.

The transition should be gradual enough that many visitors do not consciously notice it.

They should simply feel the environment becoming more creative.

When leaving the Work section, the color should gently dissolve back into black.

---

## Space

Whitespace is not empty.

Negative space creates rhythm.

It allows ideas to breathe.

Avoid filling empty areas simply because they feel unused.

The website should never feel crowded.

---

## Texture

Avoid glossy interfaces.

Avoid glassmorphism.

Avoid excessive blur.

Avoid neon effects.

Avoid visual noise.

Textures should feel organic.

Soft.

Natural.

Almost imperceptible.

---

## Contrast

Studio Errant should achieve contrast through:

- movement versus stillness
- darkness versus light
- silence versus interaction
- simplicity versus depth

Not through excessive color or decoration.

The strongest visual experiences often emerge from restraint.

# 8. Motion Language

Motion is the primary language of Studio Errant.

Typography communicates information.

Color communicates emotion.

Motion communicates life.

Animation should never exist because it looks modern. Every movement must have purpose.

The visitor should rarely notice an animation itself. Instead, they should notice how naturally the website responds to them.

Imagine entering a quiet museum where curtains move gently because of distant wind.

Nothing is dramatic.

Everything feels alive.

That is the emotional reference.

---

## Motion Principles

Every animation should satisfy at least one of these goals.

- Guide attention
- Communicate hierarchy
- Reinforce atmosphere
- Reward interaction
- Connect two ideas
- Slow the visitor down

If an animation does none of these, remove it.

---

## Motion Characteristics

Motion should feel:

Slow.

Organic.

Fluid.

Continuous.

Breathing.

Never mechanical.

Never robotic.

Never perfectly synchronized.

Nature is irregular.

The interface should borrow from nature rather than machines.

---

## Timing

Avoid dramatic easing.

Prefer:

ease-out

ease-in-out

spring animations with gentle damping

Longer durations are encouraged.

Typical durations:

Hover

150–250ms

Navigation

500–800ms

Page transition

700–1200ms

Background motion

Continuous

Never stop.

Never loop obviously.

---

## Stillness

Not every object should move.

Stillness creates importance.

For example:

Typography remains perfectly stable.

Navigation remains almost motionless.

Project cards only move when interacted with.

Meanwhile:

Background mesh continuously drifts.

Particles slowly float.

Cursor breathes.

This creates contrast.

---

## Reduced Motion

Accessibility is not optional.

Users who enable Reduced Motion should receive:

No cursor trail.

No floating particles.

Mesh movement slowed dramatically.

Transitions become elegant fades.

Hover effects rely on opacity instead of movement.

The atmosphere should remain.

Only unnecessary motion disappears.

---

# 9. The Living Mesh

The Living Mesh is the defining visual element of Studio Errant.

It is not decoration.

It is the website's heartbeat.

If Studio Errant is remembered years later, it should be because of this experience.

---

## Philosophy

The mesh represents thought before language.

Ideas before structure.

Connections before conclusions.

It should feel like something alive.

Neither liquid.

Nor smoke.

Nor cloth.

It exists somewhere between all three.

Visitors should never immediately understand what it is.

---

## Placement

The mesh begins outside the viewport.

Large flowing forms slowly drift into view from the left.

Only portions are visible at any moment.

The composition should constantly evolve.

Avoid symmetrical layouts.

Avoid centered compositions.

Nature rarely centers itself.

---

## Behaviour

The mesh should:

Morph continuously.

Stretch slowly.

Compress naturally.

Flow horizontally.

Occasionally fold into itself.

Split.

Reconnect.

Never pause.

Never teleport.

Never snap.

Motion should be mathematically smooth.

---

## Visual Style

Pure white.

Soft edges.

Semi-translucent.

Layered.

Organic.

No outlines.

No polygons visible.

No wireframes.

No glowing sci-fi effects.

No neon.

No hard shadows.

Think:

silk underwater

fog illuminated by moonlight

microscopic neural tissue

long-exposure ink in water

---

## Scroll Interaction

Scrolling should influence the mesh.

Not dramatically.

Only subtly.

Examples:

slightly increasing flow speed

small distortions

gentle stretching

slight directional influence

The visitor should feel connected to the environment without controlling it.

---

## Cursor Interaction

Desktop only.

Touch devices should ignore cursor interactions completely.

The mesh should respond softly when the cursor approaches.

Examples:

slight displacement

tiny ripples

temporary deformation

The cursor never pushes the mesh away violently.

Instead it gently influences nearby movement.

Like passing a hand through water.

---

## Technical Direction

Prefer GPU accelerated rendering.

Preferred approaches, in order:

Canvas

WebGL

Three.js

React Three Fiber

SVG fallback

If technical limitations require simplification, preserve the feeling rather than the implementation.

The emotional experience is more important than the rendering technique.

---

# 10. Cursor System

The cursor is another living element.

It should feel like a small source of awareness moving through the environment.

---

## Desktop

Replace the system cursor.

Appearance:

Small white orb.

Soft bloom.

Gentle blur.

Subtle transparency.

Diameter approximately 12–16px.

---

## Behaviour

The cursor follows the mouse using interpolation.

Never perfectly attached.

It should feel as though it has momentum.

Very slight delay.

Never sluggish.

---

## Trail

Leave an extremely subtle fading trail.

Trail disappears within one second.

Avoid exaggerated particle effects.

The visitor should barely notice it.

---

## Hover States

Interactive elements should influence the cursor.

Possible responses:

slight enlargement

brightness increase

slight ring formation

soft pulse

Avoid morphing into arrows or large circles.

Maintain elegance.

---

## Touch Devices

Disable entirely.

Touch interactions should instead use:

soft ripple animations

button opacity

gentle scaling

Never attempt to simulate a cursor on touch devices.

# 18. Responsive Behaviour

Studio Errant should never feel like a desktop website squeezed onto a phone.

Each device deserves intentional adaptation.

---

## Desktop

The complete experience.

Living mesh.

Cursor system.

Hover interactions.

Maximum atmosphere.

---

## Tablet

Preserve immersion.

Reduce mesh complexity slightly.

Simplify layouts.

Increase spacing.

Touch replaces hover.

---

## Mobile

The philosophy remains identical.

Only the interaction changes.

Disable:

Custom cursor.

Cursor trail.

Cursor mesh interaction.

Simplify:

Particle density.

Mesh complexity.

Transition duration.

Keep:

Atmosphere.

Typography.

Spacing.

Visual rhythm.

---

## Performance

If performance drops below acceptable levels,

reduce visual complexity before sacrificing usability.

The experience should remain smooth.

Fluidity matters more than visual density.

---

## Breakpoints

Design responsively rather than targeting specific devices.

Layouts should adapt naturally.

Avoid rigid pixel-based assumptions.

---

## Testing

The final website should be tested across:

Desktop browsers.

Modern mobile browsers.

Tablets.

High-DPI displays.

Ultrawide monitors.

Dark OLED displays.

Older integrated GPUs.

Graceful degradation is preferable to visual glitches.

# 19. Accessibility

Accessibility is not a checklist.

It is a design philosophy.

Studio Errant should never exclude someone simply because they experience the web differently.

The interface should be elegant for everyone.

Accessibility should never feel like a compromise.

It should feel intentional.

---

## Core Principles

The website must support:

- Keyboard navigation
- Screen readers
- High contrast
- Reduced Motion
- Logical focus order
- Semantic HTML
- ARIA only where necessary

Use semantic elements first.

Accessibility should emerge naturally from good structure.

---

## Keyboard Navigation

Every interactive element should be reachable.

Focus states should feel beautiful rather than utilitarian.

Avoid harsh browser default outlines.

Instead create elegant white focus rings that complement the design language.

---

## Reduced Motion

Living Mesh:

Extremely slow drift.

Cursor:

Disabled.

Particles:

Disabled.

Page transitions:

Simple fades.

Animations:

Opacity only.

Atmosphere should remain.

Movement should become optional.

---

## Readability

Typography should prioritize comfort.

Never sacrifice readability for style.

Maintain generous line height.

Avoid long line lengths.

Text should feel effortless to read.

# 20. Performance Strategy

Performance is part of the experience.

A beautiful website that stutters is no longer beautiful.

Smoothness is more valuable than complexity.

---

## Philosophy

Protect the emotional experience first.

Protect performance second.

Everything else is negotiable.

---

## Priority Order

If compromises become necessary:

1. Preserve philosophy.

2. Preserve fluidity.

3. Preserve usability.

4. Reduce visual complexity.

Never sacrifice smooth interaction simply to keep an effect.

---

## Performance Budget

Aim for:

Desktop:

60 FPS during interaction.

Mobile:

Smooth scrolling with no obvious frame drops.

Animations should rely on:

opacity

transform

GPU acceleration

Avoid layout thrashing.

Avoid expensive DOM updates.

---

## Progressive Enhancement

Studio Errant should scale gracefully.

High-end devices receive:

- Full Living Mesh
- Cursor system
- Rich interactions

Mid-range devices receive:

- Simplified mesh
- Reduced particle density

Low-end devices receive:

- Lightweight animated background
- Static fallback if necessary

Every visitor should receive the same atmosphere.

Only implementation complexity changes.
